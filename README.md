# QMOMKit-Couplings

Couplings of QMOMKit to external solvers.

- [`OpenFOAM-v14/`](OpenFOAM-v14) — `qmomAdvectionFoam`, a finite-volume moment
  transport solver coupled to QMOMKit in phase space, with four verification
  cases.

- [`DG-dealii-v9-8/`](DG-dealii-v9-8) — `qmomAdvectionDG`, a finite-element moment
  transport solver based on the `deal.II` library and coupled to QMOMKit in phase
  space, with five verification cases.
